New dependency: python-flint (pip install python-flint).
- 2026-11-24. builder-2D: P1 uses the polynomial weight rho = (x^2 + y^2 - 1/4)(7/4 + y^2 - x^2) instead of curved3d's piecewise flattened weight: same zero set on the square, and d rho/dx = 4x(1 - x^2) vanishes on the mirror line and on the frictionless grip, so the grip condition becomes a plain tie between B-spline coefficients.
- 2026-11-24. verifier: the independent checker (benchpack/checker) recomputes every cell, not a sample: exact rationals (Fractions) on cells inside the domain, closed forms with end points in mpmath.iv (1200 bits) on cells cut by the hole and on the patch. It is fast enough (41 s for the P1 certificate) and uses neither the builder's code nor python-flint (the builder's exact and ball arithmetic), so the two evaluations share only definitions.py.
- 2026-11-24. Harness, second code: CalculiX 2.24 (conda-forge `calculix`, win-64, in a user-level Miniforge at ~/miniforge3, env `ccx`). It installed in about five minutes and ran at once; DOLFINx would in addition need its JIT compiler chain on Windows (MSVC through cffi), an extra point of failure, so it was not tried. CalculiX expands plane-stress elements into 3D elements of the section thickness, so the harness uses a thin section (1e-3) and divides the force by it; with thickness 1 the model is a 3D slab, not plane stress.
